# Crypto Price Tracker
A Python command line application that fetches real-time cryptocurrency prices using the CoinGecko public API

## Features
- Check live crypto prices
- Supports multiple currencies
- Menu driven interface
- Basic error handling

## Tech Stack
- Python
- Requests
- REST API

## How to Run
 1. Install dependencies
    pip install -r requirements.txt

 2. Run the program
    python main.py
